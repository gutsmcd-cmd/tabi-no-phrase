# 旅のフレーズ (Travel Phrases)

旅先で、見せて伝える。海外旅行で使う基本フレーズを、相手に画面を見せて伝えるためのアプリです。無料・広告なし・ログイン不要。最初の読み込みのあとはオフラインで使えます。

- 相手の言葉を選ぶ：英語・スペイン語・フランス語・イタリア語・韓国語・中国語（簡体字）・タイ語・アラビア語・ポルトガル語・ドイツ語
- あいさつ／レストラン／買い物／交通・道／ホテル／困ったとき／数字
- 各フレーズに、日本語の意味とカタカナの読み
- タップすると大きく表示（横向きにも対応）。端末に音声があれば読み上げも
- ☆でお気に入り、マイフレーズ（住所などを自分で追加）
- データはこの端末の中だけに保存します

**English:** An offline phrasebook for Japanese travellers. Pick the local language, tap a phrase, and show it full-screen to the person you're talking to. Favorites, your own phrases, search, and an English UI. Free, no ads, no login, works offline. Data stays on your device.

Live: https://gutsmcd-cmd.github.io/tabi-no-phrase/
